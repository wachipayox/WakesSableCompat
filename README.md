# Ship Trails for Sable

Wake trails from [Wakes Reforged](https://modrinth.com/mod/wakes-reforged) for Sable ships (NeoForge 1.21.1).

## Requirements

- **Wakes Reforged 1.0.5 exactly.** Later Wakes Reforged releases ship their own Sable
  integration, which this mod does not support. The `[1.0.5,)` range in `neoforge.mods.toml`
  only sets the minimum, so the game will not stop you from installing a newer Wakes Reforged:
  pin 1.0.5 yourself.
- Sable.
