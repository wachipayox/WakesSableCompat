# Ship Trails for Sable

Wake trails from [Wakes Reforged](https://modrinth.com/mod/wakes-reforged) for Sable ships (NeoForge 1.21.1).

## Requirements

- **Wakes Reforged 1.0.5 exactly.** Later Wakes Reforged releases ship their own Sable
  integration, which this mod does not support. Since 1.0.1 the dependency range is `[1.0.5]`,
  so the game refuses to start with any other Wakes Reforged version.
- Sable.
